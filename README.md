EstateVista is a modern real estate web application built with React and Tailwind CSS, designed to showcase featured properties with advanced filtering and a clean, responsive UI.

✨ **Features**

Featured property listings

Advanced filters (city, price, property type, bedrooms, availability)

Interactive property cards

Responsive design for all devices

Modern UI with smooth user experience

🛠️ **Tech Stack**

React

Tailwind CSS

JavaScript

🚀** Getting Started**

npm install

npm start

📌 **Purpose**

This project was built to demonstrate frontend development skills, UI design, and dynamic filtering logic in a real-world real estate use case.
